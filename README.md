# Онко-скрининг: подозрения по симптомам

Мини-приложение для GitHub Pages: отмечаете симптомы — получаете вероятные онкологические подозрения,
«красные флаги» и план обследования первой линии.

Учебный проект по конспекту для зачёта (клинические рекомендации МЗ РФ / RUSSCO).
**Не является медицинским изделием и не заменяет врача.**

## Возможности

- 30+ симптомов, сгруппированных по системам (общие, дыхание, ЖКТ, мочевые, кожа, молочная железа, лимфоузлы, кости)
- «Красные флаги» — отдельная метка у симптомов и предупреждение в результате
- Ранжирование 12 онкологических подозрений по соответствию симптомам
- Учёт возраста, пола и курения (пачка-лет)
- Для каждого подозрения: обследование первой линии, ИГХ/молекулярные маркеры, куда направить
- Сводный план обследования по топ-3 подозрениям
- Схема «осмотр → диагностика → лечение»
- Адаптивная вёрстка, печатная версия, предустановки через ссылку

## Как пользоваться

1. Откройте страницу.
2. Укажите возраст, пол, курение (необязательно).
3. Отметьте симптомы (красная точка — красный флаг).
4. Нажмите «Подобрать обследование».

Ссылку с симптомами можно сохранить — параметры передаются в hash:

```
index.html#s=cough,hemoptysis,weight&age=64&smoke=35&sex=m
```

## Запуск локально

Достаточно открыть `index.html` в браузере — внешних зависимостей нет.

## Дисклеймер

Материалы носят образовательный характер, основаны на клинических рекомендациях, но не заменяют
консультацию врача. При подозрении на злокачественное новообразование обратитесь к онкологу.
