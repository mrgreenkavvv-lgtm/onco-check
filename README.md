# Онко-скрининг: подозрения по симптомам

Мини-приложение для GitHub Pages: отмечаете симптомы и уже выполненные обследования — получаете вероятные
онкологические подозрения, «красные флаги», план дообследования и тактику по выбранной стадии.

Учебный проект по конспекту для зачёта (клинические рекомендации МЗ РФ / RUSSCO).
**Не является медицинским изделием и не заменяет врача.**

## Возможности

- 30+ симптомов по системам: общие, дыхание, ЖКТ, мочевые, кожа, молочная железа, лимфоузлы, кости
- «Красные флаги» — метка у симптома и предупреждение в результате
- 21 диагностический метод (лаборатория, визуализация, эндоскопия, морфология) — отмечаете выполненное,
  приложение показывает, что осталось
- Ранжирование 12 онкологических подозрений с процентом соответствия
- Для каждого подозрения: обследование первой линии, ИГХ/молекулярные маркеры, к кому направить
- **Выбор стадии (I–IV)** — сразу показывается тактика лечения для этой стадии
- Сводный план «что осталось выполнить» по топ-3 подозрениям
- **История пациентов в localStorage**: сохранить, открыть, продолжить, удалить, экспорт в JSON
- Мобильная версия: одна колонка, крупные тап-зоны, закреплённая панель «Рассчитать / Сохранить»
- Печатная версия и предустановки через ссылку

## Как пользоваться

1. Заполните имя/ID, возраст, пол, курение (необязательно).
2. Отметьте симптомы; при необходимости — уже выполненные обследования.
3. Нажмите «Подобрать обследование».
4. Для ведущего подозрения выберите стадию — появится тактика лечения.
5. Нажмите «Сохранить», чтобы вернуться к пациенту позже (кнопка «История»).

Параметры можно передать ссылкой:

```
index.html#s=cough,hemoptysis,weight&t=ct,broncho&st=lung:III&age=64&smoke=35&sex=m
```

- `s` — симптомы, `t` — выполненные методы, `st` — стадия (`болезнь:стадия`), `age`, `sex` (`m`/`f`), `smoke` — пачка-лет.

## Данные

История хранится только в браузере (`localStorage`), на сервер ничего не отправляется.
Кнопка «Скачать JSON» в истории — резервная копия.

## Запуск локально

Достаточно открыть `index.html` в браузере — внешних зависимостей нет.
